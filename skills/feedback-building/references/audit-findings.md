# Audit Findings

Read when classifying an audit finding of the Feedback layer
or choosing its disposition.

## What to report

Report each disagreement once:

- a command the anchor document or a knowledge file names
  that does not exist, fails to start, or was renamed: **stale**, **medium**;
- a fast check over its budget: **excessive**, **medium**;
- a check that prints a full log on success,
  or more on failure than an agent can read, although the tool has a quiet mode:
  **excessive**, **low**;
- a full check with no stated duration, no way to run one test file,
  a test command that watches or prompts,
  a start command that never returns control, has no readiness check,
  or leaves processes behind,
  an observation tool the design relies on that the client does not have,
  or no statement of what a human must verify: **missing**, **medium**
  (**high** for a start or seed command that reaches production);
- tests that reach the network, depend on the clock, or fail on a second run
  (run them twice and show both runs),
  or golden files regenerated by the ordinary test command:
  **contradictory**, **medium**;
- a reviewer that can write files: **contradictory**, **high**;
  a review step with no fixed place: **invisible**, **medium**;
- a design gap: the conditions say a wrong change
  is costly or agents run unattended,
  and the agent has less to observe than the decide step recommends
  for them (a web interface nobody can look at, a service with no smoke test):
  **missing**, **medium**.

## Form and disposition

Each finding takes the form the skill's rule on findings gives:
class, severity, evidence (`path:line` or a command and its output),
source of truth, and one proposed disposition.
The source of truth is the anchor document's sentence when there is one,
the code or recipe list when a document misstates it,
and otherwise what the conditions call for, named.
The disposition is one of two: fix the named file,
or, when the recorded design is itself too thin for the conditions,
amend the design.

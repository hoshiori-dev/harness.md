# com.anthropic.claude-code

Claude Code-specific files,
namespaced as the Agent Plugins specification requires (§8).
It is the only such directory in this plugin:
Codex's client-specific data is the `extensions.com.openai` block
in `plugin.json`, and Antigravity has none.
Claude Code does not read the Agent Plugins manifest,
so `.claude-plugin/plugin.json` (generated by `just gen`)
mirrors the root `plugin.json` and points here.

- `agents/*.md` — Claude Code subagents (hand-written):
  `harness-verifier` (read-only clean-context reader dispatched by the entry
  skills after a build or improvement) and `harness-reader` (read-only
  clean-context reader dispatched to inspect outside projects and whole-project
  references without acting on them).
